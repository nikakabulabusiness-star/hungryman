# Hungryman Work 0.3.3

- Voice playback downloads authenticated attachments into a private temporary M4A/WAV file, checks the container and size, and waits for the native decoder before playing. Loading is cancellable and bounded; failed playback can be retried. Temporary files and audio focus are released when the message unmounts.
- Fullscreen map controls respect safe-area insets with additional clearance. The map uses authored navy/teal and light MapLibre styles with OpenStreetMap vector tiles. Dark is the default; theme choice persists on the device. The preview map unmounts while fullscreen is open.
- Map history keeps past scheduled/completed shoot records and dates. Cancelled records are excluded. History uses stable date/ID pagination; coincident pins show every shoot in a popup. Coordinates must have been saved on the shoot to show a pin. This does not restore deleted records.
- Shorts is an app-only bottom tab; no website page or menu was added. Native platform switches open the official YouTube Shorts, Instagram Reels and TikTok account pages inside an embedded browser. Playback/scrolling/comments follow the platform's own capabilities and sign-in requirements; this is not an API-synchronized custom feed. The embedded browser unmounts offscreen and in the background.
- Defaults: YouTube/Instagram `hungrymantv`, TikTok `hungryman.ge`. Owner/Developer can change these handles in the app. Staff cannot change sources. Only approved staff can read the configuration; arbitrary URLs and automatic app redirects are rejected.

## Verification

Mobile TypeScript and Expo lint; iOS/Android Metro export; server TypeScript; backend authorization/history/media tests; decoder lifecycle, private download, map lifecycle and Shorts navigation tests. External map module, CSS, tiles and Georgian glyph endpoints responded successfully. Native playback, iPhone safe areas and platform sign-in require physical-device verification. Managed browser preview was unavailable due to an existing supervisor server lock.

No installer build or paid service was used. Free OSM tiles are best-effort and subject to the provider's capacity and usage policy. Map styles are bundled, avoiding a separate authenticated-host fetch at startup. Tile URLs can be changed by an OTA update without a native rebuild. Attribution is retained; no bulk/offline downloads.
