## Performance and chat

A session-scoped shared resource cache retains loaded pages, deduplicates reads, refreshes in the background, and is cleared on logout/preview changes. Core hub data and the current calendar are prefetched. Outgoing chat messages appear immediately with sending/failed states; retries reuse their IDs. A long-held cursor request delivers incoming messages on detection (currently a 1.5-second server check), with no new paid realtime provider. This is long polling, not WebSockets. Reactions toggle one emoji per person; links and location snapshots open Google Maps.

## Map and attendance

HR/Owner/Developer configure the office explicitly in Management → Office and Attendance. No office location is assumed. The map uses Leaflet/OpenStreetMap with attribution and normal online tiles; Google Maps links require no paid API. The WebView is only the embedded map; all app screens and navigation remain native.

Shoot coordinates can be selected on the map; a coordinate-bearing Google Maps URL is also parsed. Text-only/shortened URLs remain usable links but cannot be pinned without coordinates.

Location collection is opt-in. Foreground checks work in Expo Go; background region monitoring and confirmation require the new native 0.3.0 binary and OS location permissions. The server only persists office presence events/times, never raw coordinates or outside-office routes. GPS is not proof of work and has accuracy limitations. Fresh office status expires after 20 minutes; unconfirmed time is capped rather than inventing complete shifts. HR can correct attendance with an audit reason. Lack of location or no answer never automatically becomes absence.

Remote-work prompts follow each employee's schedule, holidays, leave and assigned shoots. Calendar exceptions for other employees do not alter the user's own planned day. Local 13:00 reminders can be scheduled for the next 14 days and resync when the app is opened/active. Closed devices cannot receive calendar changes through this local-only method: no APNs/FCM remote-push credential has been set up. Responses are always revalidated on the server. No paid service was enabled.

Office time, office/remote/shoot days and planned workdays are separate. A day is counted once; remote confirmation never invents office hours. Totals use actual calendar days rather than hardcoding 22.
