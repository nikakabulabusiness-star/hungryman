# Hungryman Work — iPhone-ზე ტესტირება Mac-ით

ეს პაკეტი შეიცავს აპის მიმდინარე კოდს და Mac-ზე მომზადების სკრიპტს. **ეს ჯერ ხელმოწერილი IPA ან ტელეფონზე პირდაპირ დასაყენებელი ბმული არ არის.** აწყობა და უფასო Apple Personal Team-ით ხელმოწერა შენს Mac-ზე სრულდება.

## დაიწყე აქედან

არჩეულია უფასო **Personal Team** გზა. Apple Developer-ის ფასიანი წევრობა, TestFlight ან App Store-ზე ატვირთვა ამ პროცესში საჭირო არ არის.

1. ამოარქივე ZIP და გახსენი **Start-on-Mac.command**. `mobile` და `lib` საქაღალდეები ერთად დატოვე. ფაილი შეამოწმებს საჭირო პროგრამებს, მოამზადებს პროექტს და გახსნის Xcode-ს. თუ რამე აკლია, ფანჯარაში ზუსტად დაწერს რას სჭირდება დაყენება; მომწერე ეს ტექსტი.
2. Xcode → **Settings → Accounts**: შედი შენი Apple ანგარიშით. პროექტში **HungrymanWork → Signing & Capabilities**: ჩართე **Automatically manage signing**, Team-ში აირჩიე **Personal Team**.
3. შენს **iOS 26.6** ტელეფონს პირველად კაბელით შეუერთე Mac, ტელეფონზე დაადასტურე **Trust**, საჭიროებისას **Settings → Privacy & Security → Developer Mode** ჩართე და გადატვირთვის შემდეგ დაადასტურე.
4. Xcode → **Product → Scheme → Edit Scheme → Run → Build Configuration → Release**. ზედა ნაწილში აირჩიე შენი iPhone და დააჭირე **▶︎**.

თუ macOS `.command` ფაილს პირდაპირ არ ხსნის, Terminal-ში აკრიფე `bash ` (ბოლოს გამოტოვებით), Finder-იდან გადაათრიე **Start-on-Mac.command** Terminal-ის ფანჯარაში და დააჭირე Enter-ს. ეს მხოლოდ ამ ჩამოტვირთულ სკრიპტს გაუშვებს; სისტემის უსაფრთხოების პარამეტრების გათიშვა საჭირო არ არის.

**ხელმოწერა მხოლოდ Xcode-ის წარმატებული Run-ის შემდეგ იქნება შესრულებული.** ამ მომენტამდე პაკეტი საინსტალაციო IPA არ არის.

## რას მივიღებთ უფასოდ

- ცალკე Hungryman Work აპს საკუთარი აიქონით. Release რეჟიმში გახსნას Expo Go ან გაშვებული კომპიუტერი არ სჭირდება; გუნდის მონაცემებისთვის ინტერნეტი საჭიროა.
- Xcode 27-ის Device Hub-ით და iOS 27 ან უფრო ახალ სისტემაზე — Mac-თან პირველივე დაკავშირებას Wi‑Fi-ით. ძველ iOS-ზე პირველი დაკავშირებისთვის კაბელი შეიძლება დაგვჭირდეს. ორივე მოწყობილობა ერთ Wi‑Fi ქსელში უნდა იყოს.
- უფასო Personal Team-ის ხელმოწერა **7 დღე** მოქმედებს; შემდეგ Xcode-დან თავიდან დაყენება/ხელმოწერა სჭირდება. ეს არ არის შეუზღუდავი საბოლოო დისტრიბუცია.
- ამ უფასო ვარიანტში დისტანციური push შეტყობინებები გამორთულია, რადგან APNs-ის შესაძლებლობა ფასიან Apple Developer წევრობას მოითხოვს. აპის შიგნით შეტყობინებები, ხმა/ვიბრაცია და ადგილობრივი შეხსენებები ცალკე მუშაობს და მოწყობილობაზე უნდა შემოწმდეს.

მზადყოფნა: კოდი და კონფიგურაცია მომზადებულია; Mac-ზე native აწყობა, Apple-ის ხელმოწერა და რეალურ iPhone-ზე ტესტი ჯერ შესრულებული არ არის. ზარებს ჯერ არ აქვთ TURN relay, CallKit ან ფონური ზარების მხარდაჭერა; რთულ ქსელებში კავშირი გარანტირებული არ არის.

## 1. Mac-ის მომზადება

დააყენე უფასო [Xcode](https://developer.apple.com/xcode/) და ერთხელ გახსენი: დაასრულე პირველადი დაყენება და iOS კომპონენტების ჩამოტვირთვა. Xcode → Settings → Locations-ში Command Line Tools უნდა მიუთითებდეს ამ Xcode-ს. კაბელის გარეშე პირველი დაკავშირებისთვის საჭიროა Xcode 27 და iOS 27 ან ახალი.

ასევე საჭიროა [Node.js](https://nodejs.org/en/download) 24 LTS (მინიმუმ 24.3) და [CocoaPods](https://guides.cocoapods.org/using/getting-started.html). სკრიპტი მათ არსებობას ამოწმებს; ადმინისტრატორის პაროლს არ ითხოვს და სისტემურ პროგრამებს თვითონ არ აყენებს.

ამოარქივე პაკეტი. `mobile` და `lib` საქაღალდეები ერთმანეთის გვერდით დატოვე. Terminal-ში გახსენი პაკეტის `mobile` საქაღალდე და გაუშვი:

```sh
bash scripts/prepare-mac-ios.sh --check
bash scripts/prepare-mac-ios.sh
```

სკრიპტი დააყენებს პროექტის ზუსტ დამოკიდებულებებს, Expo-თი შექმნის iOS პროექტს, დააყენებს CocoaPods დამოკიდებულებებს და გახსნის `HungrymanWork.xcworkspace`-ს. Apple/Expo ანგარიშით შესვლას, გადახდას, ღრუბლოვან აწყობას ან ტელეფონზე ინსტალაციას არ ასრულებს.

თუ უფასო ვარიანტის `ios` პროექტი უკვე მომზადებულია, სკრიპტი იმავე workspace-ს გახსნის და შენს ხელმოწერის პარამეტრებს შეინარჩუნებს. სხვა ვარიანტის ან არასრული პროექტის არსებობისას შეჩერდება და მას არ გადაწერს.

### შეწყვეტილი მომზადება

თუ პირველივე მომზადება ინტერნეტის ან CocoaPods-ის შეცდომით შეწყდა, შეინახე შეცდომის ტექსტი. ახალი ამოარქივებული ასლით თავიდან დაწყება შესაძლებელია; ძველი პროექტი არ წაშალო. თუ მხოლოდ `pod install` შეწყდა, მიზეზის გამოსწორების შემდეგ `mobile/ios` საქაღალდეში გაუშვი `pod install`, შემდეგ კვლავ გახსენი Start-on-Mac.command.

## 2. Apple ანგარიშით ხელმოწერა

Xcode → Settings → Accounts-ში თავად შედი Apple Account-ით. პაროლი და დადასტურების კოდი ჩატში არ გამოაგზავნო.

პროექტის HungrymanWork target → Signing & Capabilities-ში ჩართე Automatically manage signing და Team-ად აირჩიე შენი **Personal Team**. ფასიან პროგრამაში ჩარიცხვა საჭირო არ არის.

ამ ვარიანტის bundle identifier არის `ge.hungryman.work.personal`, რათა მომავალ სადისტრიბუციო აპს არ გადაეფაროს. თუ Apple გეტყვის, რომ ეს იდენტიფიკატორი მიუწვდომელია, გამოიყენე უნიკალური დაბოლოება. ახალ ამოარქივებულ პაკეტში, მომზადებამდე:

```sh
HUNGRYMAN_IOS_BUNDLE_IDENTIFIER=ge.hungryman.work.personal.yournickname bash scripts/prepare-mac-ios.sh
```

შეცვალე `yournickname` ლათინური ასოებით. სკრიპტი ამ პარამეტრს მხოლოდ ადგილობრივ `ios-personal.local.json` ფაილში ინახავს. ანგარიშის პაროლი ან სერტიფიკატი ამ ფაილში არ იწერება. სადისტრიბუციო build/OTA-სთვის გამოიყენე სუფთა checkout ამ ფაილის გარეშე.

## 3. iPhone-ის დაკავშირება

**Xcode 27 + iOS 27 ან ახალი:** Xcode → Open Developer Tool → Device Hub → **+ → Pair Nearby Device…**. მიჰყევი ნაბიჯებს, ტელეფონზე ჩართე Developer Mode, საჭიროებისას დაადასტურე PIN და Trust. Developer Mode შეიძლება მხოლოდ დაკავშირების დაწყების შემდეგ გამოჩნდეს.

**შენი iOS 26.6:** პირველად კაბელით დააწყვილე. შემდეგ Mac და iPhone ერთ Wi‑Fi-ზე დატოვე; Xcode-ის Devices/Device Hub-ში შეამოწმე უსადენო კავშირი. თუ ტელეფონი არ ჩანს, კაბელით შეაერთე. უშუალოდ iOS-ის განახლება ამ ნაბიჯისთვის აუცილებელი არ არის.

## 4. დამოუკიდებლად გასაშვები აპი

Xcode → Product → Scheme → Edit Scheme → Run → Info → Build Configuration დააყენე **Release**-ზე. Run-ის დანიშნულებად აირჩიე შენი დაკავშირებული iPhone და დააჭირე ▶︎.

ეს ნაბიჯი აწყობს, ხელს აწერს და აყენებს აპს. თუ ტელეფონმა დეველოპერის ნდობა მოითხოვა, მიჰყევი iOS-ის მითითებას. დასრულების შემდეგ დახურე Xcode, გახსენი აპი ტელეფონის აიქონიდან და შეამოწმე, რომ Metro/Expo Go-ს გარეშე ირთვება.

უფასო ვარიანტი საკუთარ ჩაშენებულ JS bundle-ს იყენებს; OTA განახლება გამორთულია, რათა სხვა native შესაძლებლობების მქონე სადისტრიბუციო ვერსიის განახლება არ მიიღოს. ახალი კოდის ან 7-დღიანი ხელმოწერის გასვლის შემდეგ Mac-დან ხელახალი აწყობა/დაყენებაა საჭირო.

## ყოველ 7 დღეში ხელმოწერის განახლება

იმავე ამოარქივებულ საქაღალდეში გახსენი **Start-on-Mac.command**. არსებული პროექტი გაიხსნება; თავიდან პაკეტების ჩამოტვირთვა ან პროექტის გენერაცია არ მოხდება. Xcode-ში აირჩიე შენი iPhone და დააჭირე **▶︎**. ინტერნეტი საჭიროა Apple-ის ხელმოწერის გასაახლებლად.

გამოიყენე იგივე Apple Account / Personal Team და Bundle Identifier. ტელეფონიდან აპი წინასწარ არ წაშალო — განახლება არსებულ ინსტალაციაზე დააყენე. ეს ხელმოწერას განაახლებს; ახალი ფუნქციები მხოლოდ განახლებულ კოდთან ერთად დაემატება. ავტომატური ყოველკვირეული განახლება დაყენებული არ არის.

## რა მოწმდება ტელეფონზე

შესვლა/გამოსვლა, დეპარტამენტები და უფლებები, ჩატი, კლავიატურა, ფოტო/ვოისის გაგზავნა და მოსმენა, კამერა/მიკროფონი, ორი მოწყობილობის ზარი, რუკა/ლოკაციის ნებართვები და ადგილობრივი შეხსენება. უარყოფილი ნებართვისას აპი არ უნდა გაიჭედოს. აპის დახურვის შემდეგ დისტანციურ push-ს ამ უფასო ვარიანტში ნუ დაელოდები.

## QR-ით ან ბმულით დისტრიბუცია

Apple-ის ახალი ალტერნატიული დისტრიბუცია ქვეყნების მიხედვით არის შეზღუდული; საქართველოში ჩვეულებრივი IPA-ს ვებბმულიდან პირდაპირ დაყენება ამ წესებით ხელმისაწვდომი არ არის. QR მხოლოდ ბმულს ხსნის და ხელმოწერის მოთხოვნას არ ცვლის.

EAS-ის `preview` პროფილი უკვე არსებობს: რეგისტრირებული iPhone-ებისთვის Ad Hoc ინსტალაციის ბმულის შექმნა შეუძლია, მაგრამ ამას Apple Developer Program-ის მოქმედი წევრობა და შესაბამისი ხელმოწერა სჭირდება. TestFlight-იც წევრობას მოითხოვს და ბეტა ტესტირების გზაა. ფასიანი წევრობა ან სერვისი ამ სამუშაოს ფარგლებში არ გაგვიაქტიურებია.
