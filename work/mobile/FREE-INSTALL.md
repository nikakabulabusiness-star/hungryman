# Hungryman Work — უფასო დაყენება

ეს არის React Native აპი. ბრაუზერი ან Expo Go მის გასაშვებად საჭირო არ არის.

## iPhone

`ios-free-unsigned` პროფილი ქმნის რეალური iPhone-ისთვის განკუთვნილ Release IPA-ს.
ფაილი ხელმოუწერელია: მის პირდაპირ გახსნას iPhone-ზე დაყენება არ მოჰყვება.
დაყენებამდე ის თქვენსავე Apple ანგარიშს უნდა მიებას.

1. Windows-ზე ან Mac-ზე დააყენეთ Sideloadly მხოლოდ ოფიციალური საიტიდან:
   https://sideloadly.io/
2. შეაერთეთ iPhone კომპიუტერთან USB-ით და ტელეფონზე დაადასტურეთ Trust.
3. Sideloadly-ში აირჩიეთ ტელეფონი და `HungrymanWork-unsigned.ipa` ფაილი.
4. გამოიყენეთ თქვენი Apple Account და ჩართეთ Automatic Refresh. პაროლი და
   დამადასტურებელი კოდი შეიყვანეთ უშუალოდ პროგრამაში; ჩატში არ გააზიაროთ.
5. iPhone-ზე მოთხოვნის შემთხვევაში ჩართეთ Settings → Privacy & Security →
   Developer Mode და Settings → General → VPN & Device Management-ში
   ენდეთ საკუთარი ანგარიშით ხელმოწერილ აპს.

უფასო Apple ანგარიშით ხელმოწერა მოქმედებს 7 დღე. გასაგრძელებლად საჭიროა
განახლება იმავე ანგარიშით. ავტომატური განახლება საჭიროებს გაშვებულ კომპიუტერს
და ტელეფონის USB ან სწორად გამართულ Wi-Fi კავშირს. განახლების გარეშე აპი
ვადის გასვლის შემდეგ ვეღარ გაიხსნება. თითოეულ მომხმარებელს თავისი Apple
ანგარიშით დაყენება სჭირდება. ეს App Store/TestFlight გავრცელება არ არის.

განახლებისას გამოიყენეთ იგივე Apple ანგარიში და Bundle ID, რათა ძველი აპი
განახლდეს. ანგარიშის აღდგენის შესაძლებლობა ყოველთვის შეინარჩუნეთ.

ოფიციალური ინსტრუქციები და შეზღუდვები: https://sideloadly.io/faq

## Android

`preview` პროფილი ქმნის ხელმოწერილ APK-ს. ის Android-ზე პირდაპირ შეიძლება
დაყენდეს Google Play-ში გამოქვეყნების გარეშე. გახსენით ჩვენი APK და საჭიროების
შემთხვევაში დართეთ მხოლოდ მის გასახსნელ აპს ამ ფაილის დაყენების ნება.

## აწყობა

```sh
npx eas-cli@latest build --platform ios --profile ios-free-unsigned
npx eas-cli@latest build --platform android --profile preview
```

Expo-ს აწყობები გამოიყენეთ ანგარიშის უფასო ლიმიტის ფარგლებში. ფასიანი გეგმა,
Apple Developer-ის ფასიანი წევრობა და მაღაზიაში გამოქვეყნება ამ გზას არ სჭირდება.
IPA-ს წარმატებული აწყობა ადასტურებს კომპილაციას; რეალურ ტელეფონზე დაყენება და
ფუნქციების შემოწმება ცალკე უნდა დასრულდეს.
