# Android-ის უფასო სატესტო აპი

ეს გზა იყენებს თქვენს Windows/Mac/Linux კომპიუტერს. არ სჭირდება EAS-ის ფასიანი გეგმა, Google Play-ის ანგარიში ან Expo-ში შესვლა. საჭიროა ინტერნეტი კომპონენტების ჩამოსატვირთად, Node.js და Android Studio-ის SDK/JDK.

შეინახეთ პროექტის `mobile` და საერთო `lib` საქაღალდეები ერთად. Android Studio-ში SDK Manager-ით დააყენეთ SDK Platform, Build-Tools და Command-line Tools. `ANDROID_HOME` მიუთითეთ SDK-ის საქაღალდეზე. `java -version` უნდა მუშაობდეს; გამოიყენეთ პროექტის Gradle-ის მოთხოვნებთან თავსებადი Android Studio JDK.

ტერმინალში გახსენით `mobile` და გაუშვით:

```sh
npm run check:android:local
npm run build:android:local
```

პირველი ბრძანება მხოლოდ წინაპირობებს ამოწმებს. მეორე ქმნის დროებით დამოუკიდებელ ასლს, აყენებს ჩაკეტილ დამოკიდებულებებს, Expo-თი აგენერირებს Android პროექტს და აწყობს APK-ს. არსებულ iPhone/Xcode პროექტს, ხელმოწერას და ადგილობრივ პარამეტრებს არ ცვლის. დროებითი ასლი დასრულებისას იშლება.

წარმატებისას `mobile/outputs`-ში გამოჩნდება APK და SHA-256 ფაილი. გამომავალი APK აუცილებლად გადის Android-ის ხელმოწერის შემოწმებას. ფაილის სახელი მის ჰეშს შეიცავს, ამიტომ სხვა აწყობის შედეგი არ გადაიწერება.

გადაიტანეთ APK Android ტელეფონზე და გახსენით. საჭიროების შემთხვევაში ტელეფონმა ამ ფაილის გამხსნელი აპისთვის ინსტალაციის ნებართვა უნდა მოგთხოვოთ. დაყენების შემდეგ აპს Metro/კომპიუტერთან კავშირი არ სჭირდება; სამუშაო მონაცემებისთვის ინტერნეტი სჭირდება.

სატესტო აპის სახელია **Hungryman Work Test**, პაკეტი `ge.hungryman.work.local`. ის ძირითად აპთან ერთად შეიძლება დაყენდეს და არსებულ სამუშაო საიტს უკავშირდება. გამოიყენეთ მხოლოდ საკუთარი ნებადართული ანგარიში. ავტომატური OTA განახლებები გამორთულია; ახალი კოდი ახალი APK-ით უნდა დააყენოთ. ტესტირებისას შექმნილი მონაცემები რეალურ სამუშაო ბაზაში ინახება.

ეს არის სატესტო ხელმოწერა და არა Google Play-ში გასაგზავნი საბოლოო ვერსია. ფონური დისტანციური შეტყობინებები ამ ვარიანტში კონფიგურირებული არ არის. გამოშვებამდე რეალურ მოწყობილობაზე შეამოწმეთ შესვლა/გამოსვლა, წვდომის გაუქმება, ჩატი, ფოტო/ხმოვანი შეტყობინება, გადაღება და ორი მოწყობილობის ზარი.

ამ გარემოში Android SDK არ იყო ხელმისაწვდომი: სკრიპტის დამატება და კონფიგურაციის ტესტი **არ ნიშნავს**, რომ APK უკვე აიწყო. iPhone-ის უფასო პირადი ინსტალაცია აღწერილია `MAC-IPHONE.md`-ში; ეს Android პროცესი მას არ ცვლის.

საფუძველი: https://docs.expo.dev/guides/local-app-development/
